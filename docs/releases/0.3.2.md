## 新功能

- **桥接网络可设静态 IPv4**：桥接的 Linux、macOS 虚拟机可以在详情页「配置 IPv4」里填写地址、网关和 DNS，用固定地址代替路由器分配；命令行用 `macvm set --ip 地址/前缀长度 --gateway 地址 [--dns 地址]`，`--ip dhcp` 改回自动获取。运行中修改立即写进客户机，关机时修改在下次开机后生效。
- **提示是哪些 App 挡住了关机**：macOS 客户机里有 App 不肯退出（如有未存的文档）而迟迟不关机时，MacVM 会在状态里显示「等待 X 退出」，等到超时仍未关机就提示这些 App；退出 MacVM 时的等待窗口也会列出它们。`macvm stop` 超时的提示同样列出这些 App，`--json` 输出在 `error.blockingApps` 里给出。列出的是此时仍开着的 App，未必每个都在拦关机。

## 修复

- 修复静态 IP 弹窗里「手动」被误显示为「手动安装」。
- 修复关机被客户机里的 App 拦住时，每次重试关机都会在客户机里多留下一个等待中的关机请求。

## 升级与使用说明

- 静态地址需要客户机里已安装并运行 MacVM 客户机代理；macOS 客户机还需要 MacVM 保存了它的登录密码。Linux 客户机的网卡须由 NetworkManager 或 systemd-networkd 管理。
- 提示挡住关机的 App 需要 macOS 客户机里装有本版客户机代理（虚拟机运行时在详情页点「更新」，或运行 `macvm update <名>`），且关机经代理发出：MacVM 保存了客户机登录密码时直接关机，App 拦不住，也就不会出现这个提示。
- 只支持 IPv4，不支持 Windows 客户机。地址最好选在路由器的 DHCP 分配范围之外。
- 客户机里手动改过的地址、网关与 DNS，会在下次写入时改回 MacVM 配置的值。
- 克隆、存模板与从模板新建的虚拟机不带静态地址。切回 NAT 后，下次开机客户机会改回 DHCP；客户机里还留有静态地址时不能切到 QEMU 引擎，请先用 VZ 引擎开一次机。

## New

- **Static IPv4 for bridged networking**: Bridged Linux and macOS virtual machines can use a fixed address instead of one from your router. Set the address, gateway and DNS under "Configure IPv4" in the details, or from the command line with `macvm set --ip ADDRESS/PREFIX --gateway ADDRESS [--dns ADDRESS]`; `--ip dhcp` switches back to automatic. Changes apply immediately while the virtual machine runs, or after the next boot when it is shut down.
- **See which apps are blocking shutdown**: When an app in a macOS guest refuses to quit (for example, over an unsaved document) and the guest doesn't shut down, MacVM shows "waiting for X to quit" in the status and names those apps if the guest still hasn't shut down when the wait runs out; the window shown while quitting MacVM lists them too. `macvm stop` names them when it times out, and `--json` reports them in `error.blockingApps`. The list contains the apps still open at that moment, which aren't necessarily all blocking the shutdown.

## Upgrade and usage notes

- A static address needs the MacVM guest agent installed and running in the guest. macOS guests also need MacVM to have their saved login password, and Linux guests need their network interface managed by NetworkManager or systemd-networkd.
- Naming the apps that block shutdown needs this version of the guest agent in the macOS guest (click "Update" in the details while the virtual machine runs, or run `macvm update NAME`) and a shutdown sent through the agent: when MacVM has the guest's saved login password, it shuts the guest down directly, apps can't block it, and no such message appears.
- IPv4 only; Windows guests are not supported. Pick an address outside your router's DHCP range.
- Address, gateway and DNS settings changed by hand inside the guest are reset to the configured values on the next write.
- Clones, templates and machines created from templates do not carry the static address. After switching back to NAT, the guest returns to DHCP on the next boot; while the guest still holds a static address, you cannot switch to the QEMU engine until you boot it once with VZ.
